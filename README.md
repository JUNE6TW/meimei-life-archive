# MEIMEI / LIFE ARCHIVE

Soft Minimal Editorial 風格的 MEIMEI 網頁 App。

## 已建立檔案

- `index.html`：12頁網站內容
- `style.css`：奶茶灰、高留白、Editorial 樣式
- `script.js`：側邊導覽與回到頂端互動
